# `lang`

公式与技能脚本语言。只管语法：解析、名字和表的清单、写回文本、求值框架。不认识角色卡和规则包；名字怎么解析、表怎么查、骰子怎么掷都由调用方（`rules`）以回调传进来。不执行任何外部代码。

- 依赖：无
- 公式（`formula.py`）：数字、`"文字"`、`+ - * /`、比较（结果 1/0）、括号、名字（`x`、`self.x`、`this.x`、`<模板>.x`、`target.x`，含义由调用方决定）、掷骰 `NdM`（只在给了 `faces` 时允许），函数见 `FUNCTIONS`（前端“公式速查”同一张表，有测试保证一致）。`substitute` 把名字换成别的公式树（`this.<掷骰公式列>` 的展开用它）。
- 技能脚本（`script.py`）：一行一句（或用 `;` 隔开，`#` 注释），`<self|target>.<动作>(参数)`；动作见 `VERBS`。`parse_script` 返回语句，参数保留原文，出错的 `FormulaError` 带 `line`。
- 单独测试：`uv run pytest tests/lang`
