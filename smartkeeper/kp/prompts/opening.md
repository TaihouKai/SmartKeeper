任务：开场。你知道剧本的全部内容（包括 KP 专属部分）和全部角色卡。
1. 写一段给所有人的开场广播：只含公开信息。
2. 给每个玩家写一段私密开场信息：只含该玩家的角色应该知道的事。
3. 给地点起名字（places）：剧情里出现地图上没有名字、或者原名不适合直接说的地方（例如“教会”“废弃仓库”，或者给外文地名起个本地叫法），在 places 里起名字：{"name": "名字", "at": {"place": "地图上的地名或已经起过的名字", "floor": 楼层, "roof": true}}，或者 {"name": "名字", "at": {"pos": {"x": 0, "y": 0, "z": 0}}}（米）。名字和位置的对应对谁都一样、永久有效：一个名字只能指一个地方，起过的名字不能换到别处，也不能和地图上别的地物同名。谁知道这个名字是另一回事：public 为 true 是谁都知道的名字（公开的地标、所有人都被通知的集合地点），所有玩家的地图上都显示；默认 false，只有读到过提到它的消息的玩家才知道（例如敌人的工房，只有查到的人知道），没被告知的玩家看不到这个名字。新起的名字在这次输出的文字里就能用。剧本里已经起好的名字在“起了名字的地点”里，直接用。
4. 给“需要初始位置的实体”列表里的每个实体指定初始位置。用“地图”里列出的地名或“起了名字的地点”里的名字：{"place": "地名"}，在楼里可以加 "floor": 楼层（1 是地面层），在楼顶写 "roof": true。剧本已经指定了位置的实体不在列表里。

只输出一个 JSON 对象，不要输出其他文字：
{"broadcast": "...", "messages": {"<玩家 id>": "...", ...}, "places": [{"name": "名字", "at": {"place": "地名"}, "public": false}], "positions": {"<实体 id>": {"place": "地名", "floor": 1}, ...}}
