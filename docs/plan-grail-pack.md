# 计划：把圣杯战争规则书做成规则包（2026-11-25 开始）

本人的要求：把草稿“圣杯战争 (Temporary)”复制一份叫“圣杯战争”，照规则书一条条实现；引擎做不了或做得丑的地方先做新功能。
主旨：跑团沙盒，从 RP、合理性、简易性综合考量，不追求平衡。规则书可以按这个主旨调整（RP、型月设定、简化）。

## 本人已定（2026-11-25）

- 初版去掉大成功、大失败；只考虑经典 7 骑（Saber Archer Lancer Rider Caster Assassin Berserker）。
- 对魔力要按职阶加条件；骑乘要修好（加速）。
- 检定部分可以全部重写。
- 隐匿：掷骰 + “被发现”状态。气息遮蔽表 = R = 10 + 等级 × ⌈距离÷40⌉（EX 按 6），超过 200 米发现不了。
- 御主死后：玩家继续控制英灵，英灵 1d(幸运) 小时后消散（单独行动按天数）；可以和别的御主重新签约；消散后玩家出局。
- 成功等级三档：>10 成功、>15 困难成功、>20 极难成功；反击、闪避比档位。
- 初版不做战斗耗魔。日常耗魔、技能和宝具施放的消耗照做。

## 引擎新功能（按顺序）

1. [x] 检定改成数字等级：检定代码写 `level = …`（≤0 失败，越大越好）和 `levels = [...]`（名字）；`success` 是简写。
   去掉 critical_*（迁移）。difficulty 只是技能的难度，不再被对手点数覆盖（对手点数是 opp_roll）。
   opponent.template 有对象就有。新变量 distance（使用者到对象的距离）。
2. [x] 对抗按等级：脚本和 hit 条件里有 level / opp_level；技能设置 `hit`、`check = best(...)`、
   `level = …`（不掷骰、直接定等级，宝具用）、`reactions` 可以列检定和应对技能、`reactions = True`。
   技能设置 `save = "检定"`：对象对技能难度做豁免，脚本里有 saved。
3. [x] 隐匿：模板公式 `stealth`（在隐匿者身上算，distance、observer 可用；0 = 不隐匿）和 `search`（观察者的侦查骰）。
   每轮引擎替观察者掷，成功记进隐匿者的 detected_by；出感知范围就忘掉。攻击会暴露给对象。
   没发现攻击者的对象不能应对；脚本里 unseen。
4. [x] 死亡触发：模板脚本 `on_death`；脚本里可以用同伴模板名当接收者（servant.set(…)）。
5. [x] 按条目等级求和：已有 count(分组.列, 值)，不用新功能。
