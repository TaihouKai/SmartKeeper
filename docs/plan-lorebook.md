# 计划：规则包里的资料库，按关键词触发（2026-11-28 起草，未开始）

## 起因

KP 需要设定知识（认英灵、宝具效果、魔术协会和教会的规矩），但 API 模型很少主动上网搜：线上一局里只在审核角色卡时搜了 4 次，
限定 tmdict 的搜索一次也没搜到结果。用户给了一本现成的世界书（SillyTavern World Info 格式，原本给另一个跑团用）。
不能照搬：常驻大段设定、关键词乱触发，每轮会多花很多钱。

参考：CanonEngine（同一位用户的项目，`C:\Users\agent\claude\SillyTavern-CanonEngine`）的 `src/core/runtime/lore.ts`
（`keyMatch`、`entryMatches`）和 `worldset.ts`（常见词不单独触发）。只借思路、移植成 Python（用户已同意）。

## 设计

- **名字**：导入后叫“型月设定集”，作为圣杯战争规则包的资料库（文件 `rulepacks/grail/lore.json`），不带原来那本书的名字。
  格式沿用 World Info 的条目字段（`key`、`keysecondary`、`selectiveLogic`、`constant`、`disable`、`caseSensitive`、
  `matchWholeWords`、`order`、`content`、`comment`），另加一个“类别”字段。管理台规则编辑器里能导入、看、开关条目。
- **导入时整理**（一次性脚本，结果提交进仓库，以后在管理台里改）：
  - 迦勒底、特异点、异闻带和写作参考默认关闭；
  - **原作英灵（483 条，占全书 74%）、具体人物（43 条）、原作英灵专属的宝具默认关闭**。理由：
    本作的英灵多半是原创或玩家自己的诠释（这一局的匈雅提、剧本的赵云书里都没有）；就算玩家选了原作英灵，也以卡为准，
    书里是另一部作品的人设（性别、技能、宝具），会和卡打架；“认出是哪个传说”靠的是真实的历史和神话，不是游戏人设；
    玩家行动里猜一句名字就带进几百字人设，还可能顺着说漏。关闭的不删，剧本真用到原作英灵当 NPC 时可以在剧本里单独打开那几条；
  - 16 条常驻全部改成按关键词触发（规则书已经讲了基本规则）；
  - 和规则书重叠的机制条目（对魔力、骑乘、单独行动、道具作成、阵地作成、气息遮断、狂化、令咒、灵体……）保留，
    但给 KP 的说明里写明：**规则书 > 剧本 > 角色卡 > 资料库**，资料库只当背景，不改规则；
  - 每条标类别；从者和人物条目标记它的“名字关键词”（打开时用）。
- 整理后打开的约 300 条、6 万多字：世界观、组织、魔术体系、教会与死徒、圣杯战争体系、通用技能。
- **两层触发，都由代码决定**：
  1. **本局层**：开局时（和角色卡改动时）扫剧本和全部角色卡的文字（外观、生平、武器、弱点……），命中的条目整局不变，
     放在上下文的固定部分里，能吃缓存。预算约 6000 字。
  2. **本轮层**：扫本轮玩家写的行动和聊天、最近几轮的事件原文，命中的放在会变的部分。预算约 3000 字。
- **匹配规则**：照 World Info（主关键词任一命中，次关键词逻辑，`/正则/`，大小写）；英文、数字关键词只按整词；
  在超过 4% 的条目正文里出现的词不单独触发；人物和从者条目要命中名字关键词，或命中两个不同的关键词；
  只扫自然语言文字，不扫 JSON 字段名和 id；不扫规则书本身。
- **只给需要设定的调用**：检定规划、裁定、开场、审核角色卡、和 KP 聊天。写反馈、泄密检查、起代号不给。
- **记录**：每次调用记下带了哪些条目、为什么（哪个关键词、在哪段文字里），管理台能看到，方便调关键词。

## 步骤

1. 导入脚本：读 World Info JSON，分类、关闭不用的、标名字关键词，写出 `rulepacks/grail/lore.json`；规则包的数据结构和校验。
2. 触发：纯函数，带测试（主次关键词、正则、整词、常见词、名字关键词、预算截断、两层）。
3. 接进各用途的上下文（本局层在固定部分，本轮层在会变的部分），记录触发结果。
4. 管理台：导入、条目列表、开关、类别筛选；LLM 调用面板里显示这次带了哪些条目。
5. 验证：用这一局和录下的调用离线模拟几轮，看触发是否合理、字数是否在预算内；无记忆子代理当 KP 跑一轮；全部检查。

## 成本估算

按模拟，本局层约 3000～6000 字、本轮层通常不到 3000 字，合计约 2000～4500 token。
全 Luna：每轮多不到 0.1 美分；裁定用 $2/百万的模型：每轮多约 1～2 美分（本局层吃缓存后更少）。
